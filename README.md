#  SWE30003 - Assignment 3 - Object Implementation

## Dependencies
- Flask (for REST API)

## Setup
1. Install dependencies
    ```bash
    pip install flask flask-cors
    ```
2. Start the backend
    ```bash
    python app.py
    ```
    > The Flask server will start at `http://127.0.0.1:5000`.
4. Open the frontend
    Open `frontend/index.html` in your browser of choice.

## Test Accounts
A customer account is provided in `data/customers.json` - for demonstration purposes their password is included in the customer.json's Address fields.
New accounts can also be registered directly through the Customers tab.
